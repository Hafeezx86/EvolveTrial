# Student Task Tracker

A simple Python application for managing student tasks.

## Project Structure

- `src/` - Application source code
- `tests/` - Automated tests

## Project Status

Documentation and contribution guidelines are being added.

## Branching Strategy

This project uses a simple feature-branch workflow.

- `main` contains stable code.
- `feature/*` branches are used for individual features or improvements.
- Each feature branch should be reviewed through a pull request.
- Feature branches are merged into `main` after review.
